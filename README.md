# Эмулятор оболочки (вариант 7)

Эмулятор командной строки UNIX с окном на tkinter.

## Этап 1

- в заголовке окна имя VFS
- парсер понимает аргументы в кавычках
- `ls`, `cd` - заглушки, выводят имя и аргументы
- `exit` - выход

## Этап 2

Параметры командной строки:

- `--vfs` - путь к физическому расположению VFS
- `--prompt` - приглашение к вводу
- `--script` - путь к стартовому скрипту

При запуске эмулятор выводит все заданные параметры.

Стартовый скрипт выполняет команды по очереди. Ввод и вывод показываются
в окне, как при работе пользователя. Ошибочные строки не останавливают
скрипт: выводится номер строки и текст ошибки.

Пример запуска:

```
py src\main.py --vfs vfs --prompt "user>" --script scripts\start.vsh
```

## Этап 3

VFS загружается из папки на диске в память при запуске. Данные на диске
не изменяются, эмулятор работает только с копией в памяти.

Команда `vfs-info` выводит имя VFS и хеш SHA-256 ее данных.

Тестовые VFS в репозитории:

- `vfs_min` - минимальная, один файл
- `vfs_small` - несколько файлов
- `vfs_deep` - папки и файлы на четырех уровнях

Если папка VFS не найдена, при запуске выводится ошибка.

## Этап 4

Реализованы основные команды UNIX:

- `ls` - просмотр содержимого директории или файла (поддерживаются флаги `-l`, `-a` и относительные/абсолютные пути)
- `cd` - смена текущей директории в VFS (`..`, `/`, `~`, относительные и абсолютные пути)
- `clear` - очистка окна терминала
- `date` - отображение текущей даты и времени (поддерживаются форматы `+...` и флаг `-u`)

Тестирование этапа 4:
- Стартовый скрипт: `scripts/stage4.vsh`
- Скрипт ОС: `scripts/test_stage4.bat`

## Этап 5

Реализованы дополнительные команды модификации VFS в памяти:

- `rmdir` - удаление пустых директорий из памяти VFS (с проверками на существование, тип файла, непустоту и запрет удаления текущей директории)

Тестирование этапа 5:
- Стартовый скрипт: `scripts/stage5.vsh`
- Скрипт ОС: `scripts/test_stage5.bat`

## Файлы

- `src/main.py` - разбор параметров и запуск
- `src/gui.py` - окно и выполнение скрипта
- `src/shell.py` - парсер и команды
- `scripts/start.vsh` - стартовый скрипт эмулятора
- `scripts/stage3.vsh` - стартовый скрипт этапа 3
- `scripts/stage4.vsh` - стартовый скрипт этапа 4
- `scripts/stage5.vsh` - стартовый скрипт этапа 5
- `scripts/test_*.bat` - скрипты ОС для проверки параметров и разных VFS
- `scripts/test_stage4.bat` - скрипт ОС для этапа 4
- `scripts/test_stage5.bat` - скрипт ОС для этапа 5
- `vfs_min`, `vfs_small`, `vfs_deep` - тестовые VFS
- `tests/test_shell.py` - тесты

## Запуск

```
run.bat
```

## Тесты

```
py -m unittest discover -s tests -t .
```

или

```
py tests/test_shell.py
```

Каждый тест запускается и наглядно выводит входные данные и полученный результат.

## Пример

```
vfs_deep:~$ ls
docs
etc
readme.txt
vfs_deep:~$ mkdir test_dir
vfs_deep:~$ ls
docs
etc
readme.txt
test_dir
vfs_deep:~$ rmdir test_dir
vfs_deep:~$ ls
docs
etc
readme.txt
vfs_deep:~$ rmdir docs
rmdir: failed to remove 'docs': Directory not empty
vfs_deep:~$ date +%Y-%m-%d
2026-10-15
vfs_deep:~$ clear
vfs_deep:~$ exit
```
